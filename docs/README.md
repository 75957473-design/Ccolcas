# Documentación - CCOLCAS 2.1

> Distribuidora de Productos de Limpieza - Cusco
> Laravel 12 + MySQL | Vite + Tailwind

Esta carpeta `docs/` centraliza toda la documentación del proyecto. Es la que te pidieron.

## Ubicación

```
C:\Users\USER\OneDrive\Escritorio\Ccolcas2.1\docs\   <-- ESTÁS AQUÍ (proyecto de trabajo en OneDrive)
C:\xampp\htdocs\Ccolcas\docs\                       <-- copia para Apache (si entregas por htdocs)
```

> **Nota:** `htdocs` es la carpeta de Apache (`C:\xampp\htdocs\`). Solo lo que está ahí se ve en `http://localhost/...`.
> Tu proyecto real está en el Escritorio. Si tu entrega es por `htdocs`, copia esta carpeta `docs/` también a `C:\xampp\htdocs\Ccolcas\docs\`.
